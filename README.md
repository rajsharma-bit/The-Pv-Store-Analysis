# The P.V. Store — Executive Sales Dashboard (Power BI)

An interactive one-page executive dashboard built in Power BI, tracking revenue performance for a retail chain across four Philippine regions.

https://ibb.co/4gKNPQN1 
![alt text](image-2.png)

## 📌 Overview

The VP-level brief: replace a 40-tab spreadsheet with a single page that answers — how are we doing versus target, where, and in which categories — at a glance.

## 📊 Key Results

| Metric | Value |
|---|---|
| Total Revenue | ₱22.90M |
| Total Target | ₱23.48M |
| Attainment | 97.53% |
| Regions Covered | NCR, Luzon, Visayas, Mindanao |
| Categories | Beverages, Personal Care, Snacks, Household, Health & Wellness |
| Period | Jul 2025 – Jun 2026 |

## 🧭 What the Dashboard Shows

- **KPI cards** — total revenue, total target, and attainment %, front and center
- **Revenue trend** — monthly revenue by year/quarter/month, with a clear December seasonal spike
- **Revenue by category** — treemap breakdown across the five product categories
- **Revenue by region** — horizontal bar chart ranking NCR, Luzon, Visayas, and Mindanao
- **Interactive filters** — category and region slicers that cross-filter every visual on the page

## 🛠️ Built With

- **Power BI Desktop** — data modeling, DAX measures, report design
- DAX measures for revenue, target, and attainment %
- Interactive slicers and cross-filtering across all visuals
